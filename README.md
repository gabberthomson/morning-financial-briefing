# Morning Financial Briefing

PWA dimostrativa installabile tramite GitHub Pages.

## Pubblicazione
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

## Limiti attuali
Notifiche push: il pulsante richiede solo il permesso; manca ancora il servizio VAPID/backend di sottoscrizione e invio. Dati del 2026-10-08 statici e da validare prima dell'uso professionale. Nessuna pubblicazione automatica giornaliera ancora configurata.
